## 概要
これはPBL課題に関するソースコードをまとめたリポジトリです。

## 使用機器
・Raspberry Pi 3B+
・Raspberry pi camera module 2
・RPLiDAR A1M8-R6

## 環境

・raspberry pi 3B+
・ubuntu 18.04.7 LTS
・bionic

・picamera2はラズパイOSで動きます。Macで動きません。
・python3.11.xを使ってください
・ubuntuのバージョンの影響で、Pythonは手動でインストールする必要があります。
